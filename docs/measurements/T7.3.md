# T7.3 Instrument window stub

**Status: `needs-human`. Ready for Orion reference certification (`< 16 ms` p99 at `60 Hz`, with `30 Hz` fallback comparison recorded in the same campaign).**

Per Hard Rule 3 and `canvas-plan.md` §2.1, only the Orion reference machine certifies budgets; the Windows measurements recorded here are non-reference diagnostics and certify nothing.

## Summary of implementation

- **`crates/omnia-canvas/src/instrument_host.rs`** (re-exported from `crates/omnia-canvas/src/lib.rs`):
  - Implements `InstrumentStub` (and `InstrumentRate::{Hz60, Hz30}`, `frame_stride`, `InstrumentPaintScope`, `DEFAULT_INSTRUMENT_SIZE = (576.0, 468.0)` per `UK10`, `DEFAULT_TRACE_COLUMNS = 512`) holding ONLY the animated dual-trace stub content (no floating frame, drag, stacking, or focus handling, which belong to `ui-roadmap.md` `U4.1` and mount this stub in `U5.5`).
  - Uses a custom `gpui::Element` (`InstrumentTraceElement`, `G8`) painting inside `window.paint_layer` (`G5`) with `snap_px` device-pixel snapping (`D4`) and zero warm heap allocations (`B10`, `Q5`).
  - Uses `omnia-theme` tokens exclusively (`instrument/screen`, `stage/tag-text`, `probe/a`, `probe/b`) with no colour literals (`INV6`, `Q2`, `UQ6`).
  - Self-notifies via GPUI `window.on_next_frame` (`G16`) at `frame_stride(window.refresh_interval(cx), rate)` so `InstrumentStub` repaints on its target cadence while embedded in `.cached(...)` above `CachedSheet` / `OverlayView` (`G6`, `D7`, `INV11`), and drops pending ticks cleanly when stopped (`B8`).
- **`crates/omnia-bench/src/{harness.rs,main.rs,scripts.rs}`**:
  - Added `bench run --script pan --instrument [--instrument-hz 60|30]` (and headless support under `--features headless`), hosting `InstrumentStub` directly in a `.cached()` slot above the sheet without `U4.1`'s frame, wrapping stub paint work in `BenchInstrumentScope` (`B10`/`Q5`), and reporting `instrument.{hz, stride, paints, renders, ticks, size_logical}` while leaving non-instrument configs and baselines byte-for-byte unchanged.
- **`docs/measurements/T7.3/`**:
  - Added [`gate.py`](T7.3/gate.py), [`test_gate.py`](T7.3/test_gate.py), and [`owner-run.sh`](T7.3/owner-run.sh) for Orion reference execution at 100% and 125% scaling (`10k-pan-inst60` and `10k-pan-inst30`, 10 interleaved repetitions each, `OMNIA_BENCH_TRACE=1`).
