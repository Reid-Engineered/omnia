## Changes prepared for the gate

- **`crates/omnia-bench/src/drag_part.rs`** (and wiring in `driver.rs`, `harness.rs`, `scripts.rs`, `main.rs`, `lib.rs`): Implemented `bench run --sheet <stress> --script drag-part` (plus `--headless` support) using public `omnia-canvas` / `omnia-doc` APIs only. Mounts `OverlayView` with `BenchOverlayScope` over a generated stress sheet (`seed = 42`), focuses `OverlayView` at open (`T4.3`/`T5.2` focus precondition), locates the hit-testable visible part nearest the viewport centre, and builds a deterministic closed perimeter of grid-step waypoints inside the viewport and K1 bounds where every step changes `drag_delta` and keeps the ghost visible. Dispatches `MouseDown(Left)` in a pre-warmup phase (`DragPhase::Press`) so pointer capture rebinds cleanly before warmup step `0` (recorded in `frames.startup_draws` so `T1.6/attribute.py` aligns exact draw counts); warmup step `0` lifts the drag off `SheetView` (`lift_sheet_paints == 1`), and every measured frame dispatches one `MouseMove(Left held)` across the waypoints while asserting `sheet_paints == 0` (`INV11`), `revision_changes == 0` (`INV5`), `overlay_paints == frames`, `transitions == frames`, `mismatches == 0`, and `allocs_per_frame.ours == 0` (`B10`). Reports `metrics.sheet_paints` and `drag.{part_id, overlay_paints, sheet_paints, lift_sheet_paints, transitions, mismatches, revision_changes, waypoints}` alongside standard `dirty_to_present_ms` (`B6`), `frame_ms` (`B3`/`B4`/`B5`), `allocs_per_frame`, `memory_mb` (`B9`), and `diagnostic_trace`. Existing `pan`/`zoom`/`hover` scripts and `bench-baseline/` CI baselines are unchanged.
