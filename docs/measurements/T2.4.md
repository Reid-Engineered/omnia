## Generation

Ten consecutive calls to `generate(StressSheet::Parts10k, seed)` with seeds 0 through 9.
The timer includes symbol library creation, seeded part/text/wire generation, validated
bulk insertion and point-map construction. It stops before `black_box(doc)` and document
destruction. Compilation is excluded. No warm-up call was discarded.

Each document has exactly 10,000 parts and 20,000 nonzero axis-aligned wire segments.

Reproduction in the full harness (also installs the test CountingAlloc):

```powershell
cargo test --release -p omnia-bench generate::tests::measure_10k -- --ignored --nocapture
```

The observations above used a small console Cargo driver at
`$env:TEMP/omnia-t24-measure` to avoid building GPUI in release. Its dependencies are local
path dependencies on `crates/omnia-doc` and `crates/omnia-symbols`; its main imports the
unchanged generator source via `#[path = "<repo>/crates/omnia-bench/src/generate.rs"] mod generate;`.
Run it with `cargo run --release --manifest-path $env:TEMP/omnia-t24-measure/Cargo.toml`.
Driver body:

```rust
for seed in 0..10 {
    let start = std::time::Instant::now();
    let doc = generate::generate(generate::StressSheet::Parts10k, seed);
    let elapsed = start.elapsed();
    std::hint::black_box(doc);
    println!("seed={seed}: {:.3} ms", elapsed.as_secs_f64() * 1000.0);
}
```

## Correctness and scope

Tests cover all five sheets at seeds 0, 42 and u64::MAX: deterministic documents, differing
seeds, exact counts, RON round trips, K1 bounds, K2 lattice pins/endpoints, INV1, unit-segment INV2 geometry, and INV3
against a brute-force incidence count. Text-heavy has 12,000 designator/value characters.
Doc tests cover empty sheets, Unicode/escaped text, removed slots of every item kind,
future ID allocation, revision retention, derived junctions, invalid wire/part/pin/label
geometry and orientation/version rejection, and writer errors.

RON v1 embeds symbol-local pins and preserves arena holes and revision. Symbol IDs refer
to the library that generated the sheet; this is a self-contained test format, not a
production symbol interchange format. `Doc::load` rebuilds incidence through validated
inserts. No spatial index is introduced here. The T2.2 synthetic 10k benchmark can switch
to this shared generator later; it is deliberately untouched by T2.4.

`cargo test --workspace`, and `cargo deny check` (existing warnings only).
