# T2.7 Orion milestone 2 gate

The runner is ready for an owner-attended reference session. Reference results are pending.

From a clean checkout of the campaign revision on Orion, build the release bench before
starting the reference session:

```sh
cargo build --release --locked -p omnia-bench
```

Run in the active Wayland session on AC, with the bench in the foreground and other apps
closed. Choose a new output directory:

```sh
kde-inhibit --power --screenSaver python3 -B docs/measurements/T2.7/gate.py run docs/measurements/T2.7/orion
```

The runner restores the original panel scale on exit. A complete campaign records 120 reports
at 100% and 125%, ten repetitions per case and scale. For B2 it rotates the startup pair
with the motion cases, alternates the pair's order, and reports the median and range of
paired deltas between ten-sample run medians. Motion runs use 600 warmup and 600 measured
frames, covering a full zoom sweep in each phase. B3 and B4 use the median of run p99s and
the section 2.1 trace attribution for each run. B5, B9 and B10 must hold in every applicable
run.

Keep the output directory with its raw reports, logs, binary and source fingerprints,
frozen order, and before/after snapshots. Review the process snapshots against the reference
conditions. Exit 0 means the completed campaign passed, 1 means a budget missed, and 2
means the evidence was incomplete or the conditions were invalid. An interrupted campaign
keeps its partial evidence and its incomplete status.

Reproduce the verdict without launching the bench:

```sh
python3 -B docs/measurements/T2.7/gate.py summarize docs/measurements/T2.7/orion
```

Record the reference results here before closing the gate. If B4 misses, apply the
roadmap's far-zoom outcome before reporting the result.
