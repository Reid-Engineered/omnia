## Changes prepared for the gate

- **`crates/omnia-bench/src/drag_wire.rs`** (and wiring in `driver.rs`, `harness.rs`, `scripts.rs`, `main.rs`, `lib.rs`): Implemented `bench run --sheet <stress> --script drag-wire` (plus `--headless` support) using public `omnia-canvas` / `omnia-doc` APIs only. Mounts `OverlayView` with `BenchOverlayScope` over a generated stress sheet (`seed = 42`), focuses `OverlayView` at open (`T4.3`/`T5.2` focus precondition), waits through the Wayland-safe `Settle` phase (matching `drag_part.rs`), switches to `Tool::Wire`, and clicks (`MouseDown` + `MouseUp`) an in-viewport start anchor (`Pin` nearest viewport centre) to open a live wire chain without editing the document (`press_sheet_paints == 0`, `INV11`; `revision_changes == 0`, `INV5`). Builds a deterministic closed loop of in-viewport waypoints probing all five WD5 snap classes and interleaving every class reachable on the sheet (`Pin`, `WireEnd`, and `Grid` on `1k`; `Pin`, `WireEnd`, `Junction`, and `Grid` on `dense` — per `canvas-roadmap.md` T2.4 follow-up, generated sheets use half-grid stubs so no generated sheet produces `WireBody` snaps and only `dense` produces `Junction`s) with non-collinear two-leg WD6 L-route previews, verifying that every consecutive step (including wrap-around) transitions `WireGesture::snap` so `OverlayView` repaints every frame (`overlay_paints == frames`, `transitions == frames`, `mismatches == 0`). Because `OverlayView::on_mouse_move` wraps `ToolMachine::pointer_move_with_snap` (live `omnia_doc::snap` + WD6 first-leg logic) in `OverlayPaintScope::omnia` and `paint_wire_preview` runs inside `run_omnia`, `allocs_per_frame.ours == 0` (`B10`) accounts for both live snapping and preview painting. Reports `metrics.sheet_paints` and `wire.{start, overlay_paints, sheet_paints, press_sheet_paints, warmup_sheet_paints, transitions, mismatches, revision_changes, waypoints, two_leg_frames, snap_classes}` alongside standard `dirty_to_present_ms` (`B6`), `frame_ms` (`B3`/`B5`), `allocs_per_frame`, `memory_mb` (`B9`), and `diagnostic_trace`. Existing `pan`/`zoom`/`hover`/`drag-part`/`drag-segment` scripts and `bench-baseline/` CI baselines are unchanged.
