# T4.2: hit testing and snapping

Measured 2026-11-16 on the Windows development machine, **not the Q4 reference machine**.
B7 (< 0.2 ms p99) remains for the Orion reference machine under plan section 2.1.

- ASUS TUF Gaming F16 FX608JMR; Intel Core i7-14650HX.
- NVIDIA GeForce RTX 5060 Laptop GPU and Intel UHD Graphics.
- Active adapters report 1920 x 1080 and 1920 x 1200, both 60 Hz.
- Desktop registry reports Win8DpiScaling=0; per-monitor scaling was not measured.
  This CPU-only command opens no window and does no GPU work. The workload models
  100% zoom (20 px per 2.54 mm grid step); K14's 4 px tolerance is 508,000 nm.
- Windows, Rust 1.98.1, release profile, CountingAlloc installed by the bench binary.
  Power settings and background load were not controlled.

## Protocol

```powershell
cargo run --release -p omnia-bench -- hit --sheet 10k --json docs/measurements/T4.2-hit.json
```

The real T2.4 `Parts10k` generator, seed 42: 10,000 parts and 20,000 wires.
Index construction, symbol lookup setup, probe generation, and warming every probe
are excluded from timing. Each of 20,000 individually timed queries includes the
index query, transformed symbol bounds lookup, exact distance filtering, nearest
item/tie selection, and timer/black-box overhead. Scratch capacity is reused.
Percentiles are nearest rank, reported in milliseconds. Probe preparation covers
part origins, nearby and larger offset points, wire endpoints and wire midpoints; a
coprime stride spreads measured queries across the entire sheet.

## Results

Raw report: [T4.2-hit.json](T4.2-hit.json).

20,000 samples; 18,610 hits. Mean 0.0008 ms; p50 0.0008 ms; p95 0.0013 ms;
p99 **0.0016 ms**; max 0.0553 ms. These observations are below the numerical B7
threshold, but do not certify it: this is not the reference machine.


## Correctness and integration

Property tests compare indexed picking with an independent brute-force scan and
check INV9 with all orientations, long axis-aligned wires, full-sheet coordinates,
positive grid sizes through i32::MAX, and dense arbitrary off-grid pin/wire geometry.
Focused tests cover inclusive Euclidean tolerance, body interiors, deterministic
ties, sheet edges, removed slots, pins outside body bounds, priority order and
multi-step settling. No timing assertion or property-test range was weakened.

`Doc::pins`, `parts`, `wires`, `labels` are read-only. The interaction index takes
symbol-local bounds through a closure because omnia-symbols depends on omnia-doc.
Its part entries include body bounds and pins. Transformed body bounds are clamped
to K1 for both indexing and picking so edge-straddling art stays pickable. Labels
currently use anchors. Rebuild the index after document edits
until Doc owns it; future commands should maintain those bounds incrementally.
Snapping settles through higher priority tiers after projection/rounding to make
INV9 hold, so the final position can exceed the original search radius. Grid
fallback clips to the outermost in-sheet grid line. See plan section 9.
