- **`docs/measurements/T4.6/gate.py`** (and [`test_gate.py`](T4.6/test_gate.py), 5/5 tests passing): Frozen Milestone 4 Orion campaign script built on `T3.4`'s gate (`performance` governor on all 4 CPUs, AC power, native `1920×1080 @ 60 Hz` at `100%` and `125%`, 10 rotating interleaved repetitions per scale, full missed-refresh attribution via [`docs/measurements/T1.6/attribute.py`](../T1.6/attribute.py)). ## Orion reference run instructions

From a clean checkout on Orion (AC power, `performance` governor on all 4 CPUs, other apps closed, native `eDP-1` 1920×1080 @ 60 Hz, local Wayland session; pass `-B` / `PYTHONDONTWRITEBYTECODE=1` so Python does not write `__pycache__` into the clean tree):

```sh
cargo build --locked --release -p omnia-bench
PYTHONDONTWRITEBYTECODE=1 kde-inhibit --power --screenSaver python3 -B -u docs/measurements/T4.6/gate.py run docs/measurements/T4.6/orion-$(date +%F)
```

Replay an archived campaign without re-running benchmarks:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B docs/measurements/T4.6/gate.py summarize docs/measurements/T4.6/orion-<date>
```
